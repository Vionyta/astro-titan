### Summary
Deployed Software based Micro-Segmentation to isolate PCI-DSS servers. illumio using Operating System native firewall to perform micro-segmentation, support almost all the Server OS such as Windows, Linux, AIX, Solaris, HP-UX, etc. Deployment was automated via SSH and ability to map the surrounding network traffic then present in easy to understand Network Traffic Flow diagram in few days, as comparison to mapping manually which will take weeks or months.
