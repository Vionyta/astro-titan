# About Victor Ong Page

## Working Concept
This page is build on CI/CD concept where development/coding is perform on laptop, then sync to github. After sync completed, Cloudflare Page will grab the changes then build the pages according to desire setup.

```
(My Laptop) <---> GitHub (Dev branch) <---> Cloudflare Page (Dev Branch)
                      |                     https://dev.vionyta.com
                      |
                      | Pull Request (upon visual confirmation on Dev Branch)
                      |
                      V
                  Github (Production) <---> Cloudflare Page (Production) 
                                            https://victorong.vionyta.com
```
